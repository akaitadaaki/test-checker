# ログイン

## 正常系

- [ ] LOGIN-001 正しいID/PWでログインできる
  - 手順: ログイン画面で `test@example.com` / `password` を入力して「ログイン」を押す
  - 期待: ダッシュボードへ遷移する
- [ ] LOGIN-002 「ログイン状態を保持」で再訪時も維持される
  - 手順: 「ログイン状態を保持」をONにしてログインし、ブラウザを再起動してトップへアクセスする
  - 期待: ログイン済みのままダッシュボードが表示される

## 異常系

- [ ] LOGIN-101 存在しないIDでエラー表示
  - 手順: `nobody@example.com` / 任意のPWを入力して「ログイン」を押す
  - 期待: 「メールアドレスまたはパスワードが違います」と表示され、画面遷移しない
- [ ] LOGIN-102 PW 5回ミスでロックされる
  - 手順: 正しいIDで誤ったPWを5回続けて送信する
  - 期待: 5回目で「アカウントがロックされました」と表示され、正しいPWでもログインできない

## 境界値

- [ ] LOGIN-201 PW 最大長(64文字)で登録したアカウントでログインできる
  - 手順: 64文字のPWを持つアカウントでログインする
  - 期待: ダッシュボードへ遷移する

# パスワード再設定

## 正常系

- [ ] RESET-001 再設定メールが届く
  - 手順: 「パスワードをお忘れですか」から登録済みメールアドレスを送信する
  - 期待: 1分以内に再設定リンク付きメールが届く

## 異常系

- [ ] RESET-101 期限切れリンクでエラーになる
  - 手順: 発行から24時間以上経過した再設定リンクを開く
  - 期待: 「リンクの有効期限が切れています」と表示され、再発行への導線がある
